# Kimberly Maure Portfolio

Portable backup of the approved published portfolio website.

## Project type

Static HTML, CSS, and JavaScript. The CSS and primary interaction script are embedded in `index.html`; bilingual content is stored in `translations.js`.

## Run locally

Open `index.html` directly in a browser, or serve this folder with any static web server.

Example:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Hosting

The project can be deployed as-is to GitHub Pages, Netlify, Vercel, Cloudflare Pages, or another static host. Use the repository root as the publish directory. No build command is required.

## Files

- `index.html` — complete page structure, styling, and interactions
- `translations.js` — English/Chinese language-switching content
- Image files — splash-screen and transition assets used by the site

No ChatGPT login, private workspace URL, server runtime, package installation, or framework build is required.
